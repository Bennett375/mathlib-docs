# Guides

These guides are task-oriented. Each one introduces a module, shows a minimal example, and links to the exact API reference for full signatures and failure behavior.

| Guide | What it covers |
|---|---|
| [PID control]({{ site.baseurl }}/guides/control.html) | Proportional, integral, and derivative control for mechanisms |
| [State estimation]({{ site.baseurl }}/guides/state-estimation.html) | Kalman, extended Kalman, Gaussian mixture, and particle filters |
| [Field geometry]({{ site.baseurl }}/guides/geometry.html) | Points, circles, intersections, and angle helpers |
| [Linear algebra]({{ site.baseurl }}/guides/linear-algebra.html) | Matrices, vectors, Gaussian distributions, and solvers |
| [Arithmetic and random]({{ site.baseurl }}/guides/arithmetic-and-random.html) | Constants, arithmetic helpers, and repeatable random samples |
| [Tuning]({{ site.baseurl }}/guides/tuning.html) | Practical directions for controllers and filters |
| [Task recipes]({{ site.baseurl }}/guides/task-recipes.html) | End-to-end snippets for common robot tasks |
| [Troubleshooting]({{ site.baseurl }}/guides/troubleshooting.html) | Symptoms, likely causes, and what to check |

If you are new to the library, start with [Getting Started]({{ site.baseurl }}/getting-started/getting-started.html) and the [Quick Start]({{ site.baseurl }}/getting-started/quick-start.html).
