# Installation Guide
To install this project, run the following command:

```bash
pros c add-depot Mathlib https://raw.githubusercontent.com/Bennett375/Mathlib/depot/stable.json
pros c apply Mathlib
```

__Note__: This project is built on Microsoft's Visual Studio Code and Purdue ACM Sigbot's PROS
> Install Visual Studio Code [here](https://code.visualstudio.com/){:target="_blank"}

> If you don't have pros installed, get it through the vs code extension store. [PROS installation Instructions](https://pros.cs.purdue.edu/v5/getting-started/){:target="_blank"}
